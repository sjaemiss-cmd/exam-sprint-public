목요일·금요일 공통 UI: 상단 과목 탭 → 학습 홈 / 개념 정리 / 오답 복습. `layout.js`와 `layout.css`가 공통 화면을 담당합니다. 과목 엔진과 저장 키는 그대로 유지합니다. 설치·백업은 우측 설정 메뉴에 있습니다.

**10월 23일 데이터분석개론**은 [금요일 학습 화면](friday.html): 12단원, 69문제(코드 12개·공식 7주차 해답 기반 복습 9개 포함), 90분 자체 모의시험. 뉴스큐레이션과 진도를 분리해 저장합니다.
화요일 생활속의 물리·GMSW는 [기존 학습 화면](tuesday.html)에 보존했습니다.

[REA를 이용한 Openlet 분석 및 재구현 기록](REVERSE_ENGINEERING.md).

시험 전 기초 설명, 회상 연습, 서술형 자기점검, 오답 복습용 PWA.

- 빌드 없는 HTML/CSS/JavaScript. GitHub Pages로 루트 전체를 배포합니다.
- 로그인 및 서버 저장 없음. 답안과 학습 진도는 브라우저 localStorage에만 저장됩니다.
- 첫 접속 후 서비스 워커가 앱과 학습자료를 캐시하여 오프라인 학습을 지원합니다.
- 업데이트할 때 `sw.js`의 캐시 버전을 올립니다. 기존 이용자는 새 버전 적용 버튼을 누를 수 있습니다.
- 논문 링크와 학습 설계 설명은 앱 안에 있습니다. 강의 원본 파일·학교 인증정보는 포함하지 않습니다.
- 외부 논문 링크는 인터넷이 필요합니다.
