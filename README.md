# 집중 회상

시험 전 기초 설명, 회상 연습, 서술형 자기점검, 오답 복습용 PWA.

- 빌드 없는 HTML/CSS/JavaScript. GitHub Pages로 루트 전체를 배포합니다.
- 로그인 및 서버 저장 없음. 답안과 학습 진도는 브라우저 localStorage에만 저장됩니다.
- 첫 접속 후 서비스 워커가 앱과 학습자료를 캐시하여 오프라인 학습을 지원합니다.
- 업데이트할 때 `sw.js`의 캐시 버전을 올립니다. 기존 이용자는 새 버전 적용 버튼을 누를 수 있습니다.
- 논문 링크와 학습 설계 설명은 앱 안에 있습니다. 강의 원본 파일·학교 인증정보는 포함하지 않습니다.
- 외부 논문 링크는 인터넷이 필요합니다.
